# Робоход — командуй роботом

Учебный демопроект для 5–7 классов. Восемь интерактивных уровней знакомят ученика с последовательностями, отладкой и циклами. Нужно составить программу из стрелок и довести робота до зарядной станции.

## Запуск

Нужен Node.js 18 или новее. Самому сайту не нужны установка пакетов, сборка, серверная база данных или ключи API.

```bash
npm run dev
```

Откройте `http://127.0.0.1:4173`. Альтернативный запуск: `python3 -m http.server 4173 --directory dist`.

Не открывайте `index.html` через `file://`: приложение использует JavaScript-модули, для которых нужен HTTP. Для публикации на обычном статическом хостинге загрузите содержимое `dist/`.

## Проверки

```bash
npm ci
npx playwright install chromium
npm run check
npm run test:e2e
```

`npm run check` проверяет синтаксис и запускает 15 проверок модели игры. `npm run test:e2e` запускает 13 сценариев в Chromium, включая полный проход и размеры 360, 390, 768 и 1440 px. Playwright сам поднимает локальный сервер и закрывает его после проверки. На минимальной Linux-системе могут понадобиться системные библиотеки браузера: `npx playwright install --with-deps chromium`.

Отчёт находится в `playwright-report/`, снимки — в `artifacts/`. Проверка уже опубликованного сайта возможна командой `BASE_URL=https://your-site.example npm run test:e2e`.

## Структура

- `dist/index.html`, `dist/styles.css` — разметка и адаптивное оформление.
- `dist/app.js` — интерфейс, редактор команд, анимация и локальный прогресс.
- `dist/engine.js` — независимый исполнитель программы, проверка данных и восстановление состояния.
- `dist/levels.js` — все условия, карты, подсказки, решения и учебные объяснения.
- `dist/assets/` — SVG-графика и локальные шрифты Manrope с лицензией OFL.
- `tests/` — проверки модели игры и пользовательских сценариев.
- `scripts/serve.mjs` — локальный статический сервер.
- `.openai/hosting.json` — идентификатор и настройки публикации через Sites; для другого хостинга не нужен.

В проекте нет runtime-зависимостей. Playwright — только инструмент разработки. Все ресурсы загружаются с того же домена; внешние шрифтовые сервисы во время игры не используются.

## Как работает обучение

1. Уровни 1–3: прямой маршрут, смена направления, обход преград.
2. Уровень 4: запуск готовой ошибочной программы и исправление четвёртой команды.
3. Уровни 5–8: повторение одной команды, группы команд, действие после цикла и самостоятельная задача.

Одна обычная команда передвигает робота на клетку относительно экрана. Цикл повторяет всю вложенную последовательность 2–4 раза. Вложенных циклов нет. Программа содержит до 24 блоков, тело цикла — до 8 команд, один запуск — до 80 шагов.

Победа определяется после завершения **всей** программы: робот должен оказаться на станции. Для уровней 5–8 требуется цикл. При ошибке робот остаётся на последней допустимой клетке; объяснение указывает шаг и, при необходимости, позицию внутри цикла. Следующий запуск всегда начинается со старта.

Все уровни доступны сразу. Помощь не штрафуется, но результат честно отмечается как самостоятельный, с подсказкой или с решением. Если уровень однажды пройден самостоятельно, этот результат сохраняется при последующих попытках.

## Прогресс и данные

Состояние хранится в `localStorage` под ключом `robokhod-progress-v1`. Аккаунтов, аналитических трекеров и передачи учебных результатов серверу нет. Данные разных браузеров не синхронизируются. При недоступном хранилище игра продолжает работать с предупреждением. Сброс всех результатов доступен в окне прогресса и требует подтверждения.

## Добавление заданий

Скопируйте запись в `dist/levels.js`: `id`, заголовок, цель, старт, станция, преграды, исходная программа, подсказка, решение и объяснение. Координаты — `[строка, столбец]`, от 0 до 4. Направления — `up`, `right`, `down`, `left`. Цикл имеет вид `{ type: 'repeat', count: 3, body: ['up', 'right'] }`.

В текущем демо интерфейс рассчитан на восемь уровней. При расширении замените фиксированное число 8 в навигации и прогрессе на количество заданий и добавьте пользовательские проверки новых уровней.

## Продуктовые решения

- Практика начинается на первом экране; отдельная регистрация не прерывает обучение.
- Визуальный исполнитель связывает команду и её результат. Ошибку можно понять и исправить.
- Нажатия и клавиатура вместо обязательного перетаскивания удобны на разных устройствах.
- Нет таймера, жизней и оценок: ученик пробует разные решения в своём темпе.
- Подсказки и решения написаны заранее, поэтому объяснения воспроизводимы и не требуют AI API.

Следующие улучшения: проверка со школьниками, пошаговое ручное исполнение, дополнительные задания на циклы и условные команды. Перед расширением стоит проверить сайт в Safari/Firefox и на реальных телефонах.

Видео не подготовлено по согласованному ограничению задачи.
