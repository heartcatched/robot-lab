# Робоход — командуй роботом

Учебный демопроект для 5–7 классов: **20 уровней** от последовательности команд до условий, циклов и вспомогательных алгоритмов. Ученик собирает программу из блоков, запускает её или проходит по шагам, видит ошибку и исправляет решение. В песочнице можно создать свою задачу.

Сайт: https://robot-lab-ilya.cleargrape1024.chatgpt.site

## Запуск

Нужен Node.js 18 или новее. Для самого сайта установка пакетов и сборка не нужны:

```bash
npm run dev
```

Откройте `http://127.0.0.1:4173`. Другой вариант: `python3 -m http.server 4173 --directory dist`. Через `file://` JavaScript-модули не работают: нужен HTTP-сервер. На обычном статическом хостинге разместите содержимое `dist/`.

## Как учиться

| Уровни | Практика |
| --- | --- |
| 1–4 | Последовательность, маршруты, обход препятствий, отладка |
| 5–8 | Повторение команд и действия после цикла |
| 9–10 | Закрашивание текущей клетки и рисунок в цикле |
| 11–12 | «Если», обе ветки, проверка свободного пути |
| 13–16 | «Пока», неизвестное число шагов, условие внутри цикла, поиск прохода |
| 17–20 | Алгоритмы А/Б/В, вызовы из цикла, разбиение задачи на части |

Все уровни доступны сразу. У 11–16 и 20 по три поля: одна программа должна решить все варианты. Их можно просмотреть до запуска; после успешного выполнения показанного поля проверяются остальные. Завершение определяется после **всей** программы. Попадание на станцию в середине выполнения ещё не победа.

Пунктир отмечает клетки для закрашивания. Требуется точный рисунок: уже закрашенные клетки плюс целевые; лишняя закраска считается ошибкой. Повторная закраска одной клетки безопасна. Края поля, камни и стены между клетками препятствуют движению.

Команды добавляются кнопками. Выбранный блок можно заменить, переместить внутри списка или удалить вместе с его содержимым. «Добавлять сюда» задаёт место вставки в основной программе, теле цикла или ветке условия. Вкладки А/Б/В содержат отдельные алгоритмы.

«Запустить», «Пауза», «Продолжить», «Шаг» и «Стоп» используют один исполнитель. Шаг — движение, закраска, проверка условия, начало повтора, вызов или возврат из алгоритма. Во время выполнения и паузы редактирование заблокировано; «Стоп» возвращает исходное поле и сохраняет команды. После завершения можно редактировать сразу.

Вкладка «Код КуМир» показывает эквивалентную запись блоков и подсвечивает текущую команду. Код можно копировать. Текстового редактора и полного интерпретатора языка КуМир здесь нет. Это самостоятельный учебный тренажёр с подмножеством команд исполнителя «Робот».

## Песочница и обмен

- Поле от 5 × 5 до 8 × 8, Роби, необязательная станция, камни, стены, начальная и целевая закраска.
- Инструмент «Стена»: выберите клетку, затем сторону; повторное нажатие удаляет стену. Ластик убирает камень, станцию, закраску и прилегающие стены; старт переносится инструментом «Роби».
- «Сохранить» записывает один черновик в браузер. «Мой черновик» возвращает эту версию. Несохранённые изменения предупреждают при закрытии страницы.
- «Скачать файл» сохраняет JSON с полем и **всей программой**. «Открыть файл» проверяет данные до замены проекта и запрашивает подтверждение замены.
- «Поделиться задачей» создаёт URL с названием, полем и целью. Основная программа, алгоритмы и результаты **в ссылку не включаются**. Данные находятся во фрагменте `#task=`, серверное хранилище задач не нужно.
- Открытие ссылки начинает пустое решение и не меняет сохранённый личный черновик. Чтобы сохранить чужую задачу вместо него, нужно явно нажать «Сохранить».
- Без станции и целей закрашивания можно свободно экспериментировать. Для обмена задачей нужна хотя бы одна цель.

## Прогресс и совместимость

Прогресс автоматически хранится в `localStorage` под ключом `robokhod-progress-v2`. Версия 1 (`robokhod-progress-v1`) переносится при первой загрузке: программы, результаты, самостоятельность, подсказки, решения и количество попыток. Старый ключ сохраняется как резервная копия. Первые восемь карт и решений сохранены.

Песочница использует отдельный ключ `robokhod-sandbox-v1`. Сброс учебного прогресса требует подтверждения и не затрагивает песочницу. Результат честно отмечает использование помощи; уже полученное самостоятельное прохождение не теряется.

Аккаунтов, трекеров, AI API и серверной базы нет. Прогресс разных браузеров не синхронизируется. Если хранилище недоступно, тренажёр продолжает работать и показывает предупреждение; проект песочницы можно скачать в файл.

## Ограничения

До 80 блоков во всей программе, до 3 вложенных управляющих конструкций, повторение от 1 до 10, до 1000 операций за запуск с учётом проверок условий и вызовов. До трёх алгоритмов А/Б/В без параметров и рекурсии. JSON-проект — до 128 КБ; ссылки и все входные данные проверяются. Код из импортированных файлов никогда не исполняется через `eval`.

## Проверки

```bash
npm ci
npx playwright install chromium
npm run check
npm run test:e2e
```

`check` проверяет синтаксис и 38 проверок в трёх файлах тестов: модели/миграция, исполнитель/учебные карты, проекты/ссылки. На некоторых версиях Node сводка `node --test` показывает число файлов; подробные проверки доступны через `node tests/engine.test.mjs`, `node tests/model.test.mjs`, `node tests/sandbox.test.mjs`.

21 сценарий Playwright проверяет пользовательские действия, весь маршрут, сохранение, файлы, ссылки, клавиатуру и ширины 360, 390, 768, 1440 px. Playwright запускает локальный сервер сам. На минимальной Linux-системе могут понадобиться библиотеки Chromium: `npx playwright install --with-deps chromium`.

Отчёт: `playwright-report/`; снимки: `artifacts/`. Публичный сайт можно проверить через `BASE_URL=https://robot-lab-ilya.cleargrape1024.chatgpt.site npm run test:e2e`. Результаты и границы проверки описаны в `QA.md`; состояние продолжения работы — в `PROGRESS.md`.

## Файлы проекта

- `dist/index.html`, `styles.css`, `v2.css` — разметка и оформление.
- `dist/app.js` — интерфейс, редактор, управление запуском и песочницей.
- `dist/model.js` — модель блоков и поля, проверки данных.
- `dist/engine.js` — пошаговый исполнитель и проверка целей.
- `dist/levels.js` — 20 заданий, 34 поля, подсказки и решения.
- `dist/code.js` — генерация кода КуМир.
- `dist/storage.js` — загрузка и перенос прогресса.
- `dist/sandbox.js` — формат проекта и обмен задачами.
- `dist/assets/` — исходные SVG и локальный Manrope с лицензией OFL.
- `tests/`, `scripts/serve.mjs` — проверки и локальный сервер.
- `.openai/hosting.json` — идентификатор существующего сайта и настройки Sites.
