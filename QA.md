# Проверка Робохода

Сайт: https://heartcatched.github.io/robot-lab/

Проверки логики выполнены автоматически в Node.js, браузерные проверки — через Playwright в Chromium и WebKit. Дополнительно автор проекта ранее вручную протестировал сайт на физических телефонах.

## Воспроизводимые проверки

| Проверка | Покрытие |
| --- | --- |
| 43 проверки логики | Модель блоков/поля, миграция сохранений, исполнитель, решения всех 34 полей, файлы проектов, ссылки без решения, резервные копии и отмена |
| 32 сценария Chromium | Сборка/редактирование программы, все 20 уровней, помощь, отладка, условия/циклы/алгоритмы, шаги/пауза/стоп, код КуМир, песочница, файлы, ссылки, сохранение/восстановление, клавиатура, отмена, адаптивность и развёрнутый редактор длинных программ |
| 3 сценария WebKit с мобильной эмуляцией | Запуск/шаги/перезагрузка, песочница/отмена/обмен задачами и редактирование длинной вложенной программы в эмулируемом мобильном режиме |

Команды: `npm run check` и `npm run test:e2e`. Для браузерных тестов предварительно установите зависимости по README. Все локальные браузерные проверки выполняются под `/robot-lab/`, как на GitHub Pages.

Размеры области просмотра Chromium: 320×568, 360×740, 390×844, 768×1024, 1366×768, 1440×900. В WebKit эмулируется мобильный режим с областью просмотра 390×844 и сенсорным вводом. Автоматические сценарии проверяют границы поля, редактора и управления запуском, отсутствие горизонтального переполнения.

## Дополнительное покрытие автоматических сценариев

- Кнопка «Начать тренировку» видна без прокрутки, работает через Enter. Возврат на главную предлагает продолжить выбранный уровень.
- Перезагрузка возвращает программу и прогресс без автоматического запуска.
- Неудача на одном варианте не скрывает результаты остальных полей.
- Отмена не стирает результаты прохождения, попытки и использование помощи.
- Резервная копия различает сохранённый черновик и незавершённый проект; повреждённые файлы отклоняются до записи. Ошибка записи не выдаётся за успешное восстановление.
- Ссылка на задачу не содержит решения и не перезаписывает личный черновик.
- Без localStorage тренажёр работает и сообщает, что сохранение недоступно.

## Обновление мобильного редактора — 30 октября 2026

На экране 360×740 длинный цикл обрезался: программе оставалось около 135 пикселей по высоте. Добавлена кнопка «Развернуть»: в этом режиме редактор получает около 470 пикселей на том же экране, а поле возвращается по кнопке «К полю» или при запуске/выполнении по шагам. После добавления команды автоматически показывается место вставки; параметры блоков на телефоне отображаются более крупным шрифтом.

Локально прошли `npm run check` и **35/35** браузерных сценариев. Четыре новых сценария проверяют длинную программу с тремя уровнями вложенности, добавление команды в глубокую ветку, видимость нового блока, изменение параметра, отмену, сохранность данных, код КуМир, Escape, возврат к полю при выполнении и переход к ширине планшета. Проверены 320×568, 360×740 и 390×844 в Chromium и 390×844 в мобильной эмуляции WebKit. Скриншоты обычного и развёрнутого редактора просмотрены при подготовке обновления.

## Ручная проверка на телефонах

Автор проекта выполнил ручное тестирование сайта на физических телефонах до последнего обновления редактора. Новый режим редактирования проверяется в Chromium и мобильной эмуляции WebKit; повторная ручная проверка этого обновления на телефонах пока не подтверждена.

## Границы проверки

Автоматический набор покрывает Chromium и WebKit; Firefox в него не входит. Проверка со скринридером не проводилась. Понятность заданий для школьников ещё требует пользовательского тестирования. Демопроект не является исследованием эффективности обучения.
