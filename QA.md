# Проверка Робохода

Сайт: https://heartcatched.github.io/robot-lab/

Проверки логики выполнены автоматически в Node.js, браузерные проверки — через Playwright в Chromium и WebKit. Мобильный интерфейс проверялся в браузерной эмуляции. Ручное тестирование на физических телефонах не проводилось.

## Воспроизводимые проверки

| Проверка | Покрытие |
| --- | --- |
| 43 проверки логики | Модель блоков/поля, миграция сохранений, исполнитель, решения всех 34 полей, файлы проектов, ссылки без решения, резервные копии и отмена |
| 29 сценариев Chromium | Сборка/редактирование программы, все 20 уровней, помощь, отладка, условия/циклы/алгоритмы, шаги/пауза/стоп, код КуМир, песочница, файлы, ссылки, сохранение/восстановление, клавиатура, отмена, адаптивность |
| 2 сценария WebKit с мобильной эмуляцией | Запуск/шаги/перезагрузка и песочница/отмена/обмен задачами в эмулируемом мобильном режиме |

Команды: `npm run check` и `npm run test:e2e`. Для браузерных тестов предварительно установите зависимости по README. Все локальные браузерные проверки выполняются под `/robot-lab/`, как на GitHub Pages.

Размеры области просмотра Chromium: 360×740, 390×844, 768×1024, 1366×768, 1440×900. В WebKit эмулируется мобильный режим с областью просмотра 390×844 и сенсорным вводом. Автоматические сценарии проверяют границы поля, редактора и управления запуском, отсутствие горизонтального переполнения. Это проверки в браузерной среде, без использования физических устройств.

## Дополнительное покрытие автоматических сценариев

- Кнопка «Начать тренировку» видна без прокрутки, работает через Enter. Возврат на главную предлагает продолжить выбранный уровень.
- Перезагрузка возвращает программу и прогресс без автоматического запуска.
- Неудача на одном варианте не скрывает результаты остальных полей.
- Отмена не стирает результаты прохождения, попытки и использование помощи.
- Резервная копия различает сохранённый черновик и незавершённый проект; повреждённые файлы отклоняются до записи. Ошибка записи не выдаётся за успешное восстановление.
- Ссылка на задачу не содержит решения и не перезаписывает личный черновик.
- Без localStorage тренажёр работает и сообщает, что сохранение недоступно.

## Границы проверки

Мобильная эмуляция WebKit не подтверждает работу Safari на настоящем iPhone. Проверки на физических iPhone/Android, в Firefox и со скринридером не проводились. Понятность заданий для школьников ещё требует пользовательского тестирования. Демопроект не является исследованием эффективности обучения.
