## Короткое описание для отправки

«Робоход» — учебный тренажёр алгоритмов для 5–7 классов. Я выбрал практику с роботом: ученик собирает программу из блоков, видит результат на поле и исправляет ошибки. В проекте 20 уровней: последовательность, повторы, закраска, условия, циклы «пока» и вспомогательные алгоритмы. Есть пошаговое выполнение, показ кода КуМир и песочница с обменом задачами без решения.

Использовал Codex для проектирования, реализации и проверки; HTML, CSS и JavaScript; Node.js и Playwright с Chromium/WebKit; GitHub Actions и Pages для публикации. Проект делал в несколько сессий 29–30 октября: базовая версия и первое расширение заняли суммарно около полутора часов, последующие доработки выполнялись с перерывами. Точное активное время всех доработок отдельно не фиксировал.

Проверил все 20 уровней на 34 полях, запуск по шагам, ошибки, сохранение и восстановление прогресса, файлы и ссылки без решения, отмену правок и пять размеров экрана. В проекте 43 проверки логики и 31 браузерный сценарий. Следующим шагом проверил бы понятность заданий со школьниками, протестировал реальные телефоны и добавил библиотеку пользовательских задач.

## Что приложить

1. Ссылку на работающий сайт.
2. Ссылку на репозиторий или архив исходников.
3. Запись экрана до трёх минут по исходному условию задания. Сам видеофайл пока не записан.
4. Несколько абзацев выше: идея, инструменты, время, проверки и дальнейшие улучшения.
