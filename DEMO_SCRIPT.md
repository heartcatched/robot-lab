# Сценарий записи экрана — до трёх минут

Подготовьте сайт в отдельном окне браузера. Если сразу открылся уровень, нажмите «На главную». Не нужно сбрасывать личный прогресс. Держите запись в пределах 2:50, чтобы оставить небольшой запас.

| Время | Что показать | Что сказать своими словами |
| --- | --- | --- |
| 0:00–0:20 | Главная, затем «Начать тренировку» | «Это Робоход — тренажёр алгоритмов для 5–7 классов. Ученик составляет программу и сразу видит, как она работает» |
| 0:20–1:00 | Глава «Основы», уровень 4 «Дело в одной команде». Запуск, подсветка ошибочной команды, замена её направления на «Вверх», повторный запуск | «Обратная связь показывает место ошибки. Ученик исправляет свою идею и проверяет её ещё раз» |
| 1:00–1:40 | Глава «Пока», уровень 13. Добавить «Пока» с условием «справа свободно», внутри — «Вправо». Сделать шаг, открыть «Код КуМир», продолжить запуск | «Одна программа проверяется на нескольких полях. Пошаговое выполнение и код помогают понять, почему работает цикл» |
| 1:40–2:10 | «Песочница», закрыть настройки, открыть «Поделиться» | «Можно создать своё поле, сохранить проект и отправить другу задачу. В ссылку не попадает решение» |
| 2:10–2:35 | Закрыть окно ссылки, сузить браузер или включить мобильный режим | «На телефоне поле, редактор и запуск помещаются на экране. Команды открываются отдельной панелью» |
| 2:35–2:50 | Вернуться к сайту, коротко закончить | «Сайт размещён на GitHub Pages. Я использовал Codex и проверил сценарии в Chromium и WebKit. Дальше хочу проверить задания со школьниками» |

Если приходится долго переключаться между окнами, сократите показ песочницы. Не перечисляйте все функции: достаточно показать одну ошибку, один работающий алгоритм и объяснить решения по интерфейсу. Для записи подойдёт уже установленный у вас инструмент; отдельная обработка видео не обязательна.
